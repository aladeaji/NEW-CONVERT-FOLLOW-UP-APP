# NEW-CONVERT-FOLLOW-UP-APP

New Convert Follow-up & Attendance App — ensure no new convert falls through the cracks.

> Every person is seen. Every person is assigned. Every person is followed up. Every person has a next step.

## Vision

Move people through: VISIT / CONVERSION → REGISTRATION → ASSIGNMENT → FOLLOW-UP → ATTENDANCE → CONNECTION → GROWTH → INTEGRATION → ACTIVE MEMBER

## Core workflow

REGISTER → ASSIGN → CONTACT → RECORD → SCHEDULE → ATTEND → MONITOR → RE-ENGAGE → INTEGRATE → RETAIN

## MVP scope (per PRD)

- People: registration, visitor registration, profile, search, duplicate awareness
- Assignment: manual + recommended, unassigned queue, reassignment
- Follow-up: journey stages, activities, history, next action, due/overdue tracking, reminders
- Attendance: service/activity attendance, history, declining/missing detection
- Care: notes, pastoral attention, activity timeline
- Dashboards: admin + worker (Today-focused), action/attention lists
- Reports: follow-up, attendance, retention/progress
- Users: Admin, Coordinator, Worker, Leadership
